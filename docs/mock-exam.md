# 模拟考试抽题与错题详情

每卷 40 题：从 547 道单选中抽 32 题，从 136 道多选中抽 8 题。限时 20 分钟，每题 1 分，答对 30 题合格；多选须与答案集合完全一致。

组卷时分别对单选、多选池分组，随机打乱分类顺序和分类内题目顺序，按分类轮转取题，再打乱整卷顺序。题库目前有 50 个含单选的分类、33 个含多选的分类，因此一卷分别抽到 32 个单选分类、8 个多选分类。同一分类可能同时出单选和多选。

同一卷没有重复题；不同卷独立抽取，允许重复，不读取练习进度或错题记录来加权，也没有跨卷避重。分类被选中的机会相同，但各分类题量不同，因此题目本身并非全题库等概率，小分类中的单题更容易重现。本应用没有实现官方分类配额表，不应把该分类分散策略视为官方组卷算法。

2026-10-31 修复前（基线 `35b8c02`），分类排序固定，每卷始终只从最前面的 32 个单选分类和 8 个多选分类抽取，导致 183 道单选、80 道多选永远无法入卷。修复改为每卷随机打乱分类顺序，保持题型数量、分类分散和评分规则。

固定种子 4263、连续组卷 5,000 次的对照结果如下。统计是可复现样本，不是对每次考试的承诺。

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 覆盖单选题 | 364 / 547 | 547 / 547 |
| 覆盖多选题 | 56 / 136 | 136 / 136 |
| 各单选分类入卷次数范围 | 0–5,000 | 3,124–3,286 |
| 各多选分类入卷次数范围 | 0–5,000 | 1,165–1,264 |
| 相邻两卷平均重复题数 | 10.530 / 40 | 5.787 / 40 |

错题列表保留题干摘要。点击题目按钮可打开页面内详情，查看完整题干、四个选项、正确答案、考试所选答案（未答显示“未作答”）和解析。长内容在弹窗内滚动；加入错题本是独立操作。错题本及练习成绩中的详情也使用同一弹窗，避免依赖 Android WebView 未配置的原生 JavaScript 弹窗桥接。

## 本地验证

```sh
node scripts/build-standalone.cjs
node scripts/check-categories.cjs
node scripts/check-mock-sampling.cjs
node tests/mock-exam.cjs
```

浏览器验证：在仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后使用 Playwright CLI 打开该地址并执行 `run-code --filename tests/mock-exam-browser.js`。脚本验证网页版及离线版，覆盖手机尺寸、长题干、多选、超时交卷、错题本及主题；截图保存在执行目录的 `output/playwright/`（需事先创建）。这不替代 Android 真机安装验证。

`index.standalone.html` 为生成文件；修改 `index.html` 后运行上述构建脚本。已安装的离线 APK 使用内置页面，需要重新打包更新，网页更新不会自动替换 APK 内的页面。
